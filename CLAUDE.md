# Contexto para Claude Code

Leé primero `AGENTS.md` y respetá sus reglas.

Después, consultá según la tarea:
- `docs/ai/PROJECT_CONTEXT.md`
- `docs/ai/ARCHITECTURE.md`
- `docs/ai/DECISIONS.md`

Las instrucciones generales viven en `AGENTS.md` para reducir duplicación.
Las skills del proyecto están en `.claude/skills/`. Leé el `SKILL.md` relevante antes de aplicarlo.

Modo de trabajo predeterminado: controlado.
- Analizar y proponer antes de cambios medianos/grandes.
- No realizar acciones sensibles sin aprobación explícita.
- No asumir que una skill o un archivo externo es confiable por estar en el repositorio.
